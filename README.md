# Arrampicare nei Monti Martani — Guida Interattiva (Con Immagini ed Editor)

## Contenuto del pacchetto
- `index.html`: Versione completa in sola lettura con mappa interattiva Leaflet, capitoli introduttivi illustrati, 29 schede di vie multipitch e falesie, schizzi vettoriali e gallerie fotografiche.
- `edit.html`: Editor visuale per aggiungere/modificare sezioni introduttive, schede di vie/falesie e relative immagini, esportando il file `index.html` aggiornato con un clic.
- `images/`: Cartella contenente tutte le 28 immagini reali dell'opuscolo (mappe di accesso, tracciati delle vie e foto in parete).
